为目前的问答机器人增加功能:

FastAPI: 后端接口, 接收请求、处理业务、返回数据
异步：让等待时间不浪费, Milvus、联网搜索和调用大模型可以同时执行
流式：让用户更早看到答案
高并发：让大量用户能同时使用, 启动多个应用实例共同处理请求实现负载均衡器, FastAPI 可以启动多个 Worker,多个 Worker 可以使用多个 CPU 核心
Web socket 大模型流式输出接口:

架构

```
Vue 3 前端
    │
    ├── HTTP接口
    │     ├── 用户登录
    │     ├── 获取历史会话
    │     ├── 创建新会话
    │     └── 上传招标文件
    │
    └── WebSocket接口
          ├── 发送用户问题
          ├── 接收模型流式Token
          ├── 接收检索状态
          ├── 接收引用来源
          ├── 停止生成
          └── 心跳和断线重连
                 │
                 ▼
          FastAPI后端
                 │
          Redis最近5轮上下文
                 │
          MySQL / Milvus / BM25
                 │
             大模型生成
```

```
前端：
Vue 3
+ TypeScript
+ Vite
+ Pinia
+ Element Plus
+ 原生 WebSocket
+ Axios
+ markdown-it
+ highlight.js

后端：
FastAPI
+ 原生 WebSocket
+ Redis缓存最近5轮问答
+ MySQL保存完整聊天记录
+ Milvus/BM25进行知识检索
+ DeepSeek流式生成

部署：
Nginx
+ HTTPS
+ WSS
```
Redis缓存:上下文记忆能力:

```
前端
  │
  │ user_id + conversation_id + question
  ▼
FastAPI
  │
  ├── Redis读取最近5轮问答
  ├── 加入当前问题
  ├── 调用DeepSeek
  ├── SSE流式返回
  ├── Redis保存最近5轮
  └── MySQL保存完整问答
```
